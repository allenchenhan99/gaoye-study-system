# 證券商高級業務員 考古題複習平台 — 階段 3：前端練習網站（Design Spec）

- 日期：2026-07-01
- 狀態：待使用者審閱
- 範圍：前端互動練習網站（React + Vite 靜態站）。資料來自階段 1 的 `data/questions.json`（5,400 題，答案/送分 100%）。詳解（階段 2，`data/explanations.json`）背景陸續產生，前端優雅處理「暫無詳解」。

---

## 1. 目標與技術

讓使用者在瀏覽器（含手機）練習歷屆考題：選年份、隨機、依科目、模擬考、錯題本/收藏，逐題作答有即時對錯與詳解，進度全存本機。

- **框架**：React 18 + Vite + TypeScript。
- **路由**：react-router。
- **樣式**：Tailwind CSS（乾淨、響應式、可深色模式）。
- **狀態**：純前端，無後端、無帳號；進度存 `localStorage`。
- **部署**：靜態站，可上 GitHub Pages / Vercel。

## 2. 資料

### 2.1 資料銜接腳本
寫 `scripts/export_frontend_data.py`：把 `data/questions.json` → `frontend/public/data/questions.json`（精簡欄位），`data/explanations.json` → `frontend/public/data/explanations.json`。詳解背景更新後可重跑覆蓋。

### 2.2 前端題庫格式（questions.json 每題）
```ts
interface Question {
  id: string;            // "114-1-investment-001"
  year: number;          // 114
  round: number;         // 1
  roundLabel: string;    // "第1次"
  subject: "law" | "investment" | "finance";
  subjectLabel: string;
  number: number;
  stem: string;
  options: { A: string; B: string; C: string; D: string };
  answer: "A"|"B"|"C"|"D"|null;   // 送分題為 null
  allCredit?: boolean;            // 送分題 true
}
```
### 2.3 詳解格式（explanations.json）
```ts
interface Explanation { id: string; explanation: string; /* markdown */ flagged?: boolean }
```
前端以 id 對應；查無則顯示「詳解陸續補充中」。`flagged` 的詳解照常顯示（內含複核註記）。

### 2.4 載入策略
v1 啟動時 `fetch` 單一 `questions.json`（約 2MB）一次並快取於記憶體；`explanations.json` 另外載入（可較晚、不擋作答）。題庫大時未來再按年份切檔，本版不做。

## 3. 畫面與流程

### 3.1 作答元件 QuestionCard（各模式共用）
顯示：科目/年次標籤、題號、題幹、A–D 四選項。
- **即時模式**（年份/隨機/科目/錯題本）：點選項→立即判定。正解綠底；若選錯，所選紅底＋正解綠底。判定後展開：官方答案、詳解（markdown 渲染，無則提示語）、送分標記。提供「收藏★」與「下一題」。答錯自動加入錯題本。
- **延後模式**（模擬考）：作答當下只記錄選擇、不判對錯；交卷後才一次顯示對錯與詳解。
- **送分題**：顯示「送分題（官方公告任選皆對）」，任何選擇皆判對。

### 3.2 模式
| 模式 | 行為 |
|------|------|
| 年份練習 | 選 年份→次別→科目，逐題作答；顯示該卷進度（第 n/50） |
| 隨機練習 | 全題庫（可選科目）隨機抽；可設每輪題數（預設 20） |
| 科目練習 | 三科擇一，跨年隨機抽 |
| 模擬考 | 抽 50 題、倒數計時（預設 60 分）、交卷算分（送分題算對），結果頁看分數與逐題詳解 |
| 錯題本/收藏 | 列出做錯/收藏題，可重練、移除 |

### 3.3 首頁
模式選單 + 簡易統計總覽（總作答數、整體正確率、各科正確率、錯題數）。提供「清除所有進度」。

## 4. 本機狀態（localStorage）

```ts
interface Store {
  progress: Record<string, { answeredCount: number; lastChoice: string | null; correct: boolean }>;
  wrongBook: string[];     // 答錯自動加入；答對後可移除
  favorites: string[];
  stats: {
    totalDone: number;
    perSubject: Record<"law"|"investment"|"finance", { done: number; correct: number }>;
  };
  examHistory: { date: string; score: number; total: number; bySubject: Record<string, {correct:number;total:number}> }[];
  settings: { perRoundCount: number; examTimerMin: number; darkMode: boolean };
}
```
以單一 key（如 `gaoye-store-v1`）序列化存取，集中在 `useLocalProgress` hook，版本化避免格式變更衝突。

## 5. 元件/模組結構

```
frontend/
  public/data/{questions.json, explanations.json}
  src/
    main.tsx, App.tsx (router)
    pages/ Home, PracticeSetup, QuizRunner, ExamRunner, ExamResult, ReviewBook, Stats
    components/ QuestionCard, OptionButton, ExplanationView(markdown), Timer, ProgressBar, StatCard
    hooks/ useQuestionBank, useLocalProgress
    lib/ store.ts(localStorage schema+IO), sampling.ts(抽題), scoring.ts(判分含送分)
    styles/
```
每個 page 自成一責任；QuestionCard 不知道自己被哪個模式使用（透過 props 控制即時/延後）。

## 6. 測試

- **lib 單元測試**（Vitest）：`scoring`（含送分題算對、選錯判定）、`sampling`（去重、數量、科目篩選）、`store`（讀寫、版本、錯題自動加入/移除、清除）。
- **元件測試**（React Testing Library）：QuestionCard 即時/延後兩種行為、送分題、無詳解提示。
- 不對 LLM 詳解內容做測試（屬資料）。

## 7. 風險與對策

| 風險 | 對策 |
|------|------|
| questions.json 體積（手機載入） | v1 單檔約 2MB 可接受；預留按年份切檔的未來路徑 |
| 詳解尚未產生 | 前端以 id 對應、查無顯示提示語，不擋作答 |
| localStorage 格式演進 | store 版本化 key |
| 重複題跨年 | 階段 1 保留重複題；前端隨機抽可（未來）選擇性去重，v1 不去重 |

## 8. 驗收標準

1. 五個模式皆可實際操作完成一輪練習。
2. 即時模式：選項判定正確（含選錯顯示正解）；送分題任選皆對。
3. 模擬考：計時、交卷算分、結果頁顯示逐題對錯與詳解。
4. 錯題本：答錯自動加入、可重練與移除；收藏可加入/移除。
5. 統計：總作答數、各科正確率正確累計；重整頁面後進度仍在（localStorage）。
6. 有詳解的題顯示詳解，無詳解顯示提示語。
7. lib 單元測試與 QuestionCard 元件測試通過。
8. `npm run build` 產出可部署的靜態檔。

## 9. 不在本階段範圍

- 詳解內容生成（階段 2，背景進行）。
- 後端、帳號、雲端同步、跨裝置進度。
- 題庫按年份切檔的延遲載入（預留未來）。
