高業學習系統隱私權政策

生效日期：2026 年 8 月 29 日

本系統使用 Google 登入辨識使用者，並以 Supabase 為每位使用者保存獨立的學習進度。 Google 登入不會讓其他使用者看到你的紀錄，也不會把所有人的進度存成網站擁有者的個人學習資料。

01我們蒐集的資料

  • Google 帳號基本資料：Google 提供的帳號識別碼、電子郵件地址、顯示名稱及頭像，用於建立與辨識登入工作階段。本系統不會取得你的 Google 密碼。
  • 學習進度：作答題號、答題結果、錯題、收藏、科目統計、模擬考紀錄、學習設定及同步操作識別碼。
  • 裝置快取：瀏覽器可能暫存個人進度與登入工作階段，供網路不穩時恢復與同步使用。

02資料用途

上述資料只用於帳號登入、跨裝置同步、呈現個人練習紀錄，以及改善系統穩定性。我們不會出售個人資料，也不會將個人學習紀錄用於廣告投放。

03保存位置與使用者隔離

網站由 GitHub Pages 提供靜態頁面；登入及雲端資料由 Supabase 提供。 學習資料依 Supabase Auth 核發的使用者識別碼儲存，資料庫套用 Row Level Security（RLS）， 因此每位使用者只能存取自己的資料。Google OAuth 僅作為登入身分提供者。

04保存期限與刪除

個人進度會保留至使用者主動清除或提出帳號刪除要求。你可在登入後使用「清除所有進度」移除學習紀錄； 若要查詢、更正或刪除帳號及其相關資料，請使用下方聯絡方式提出要求。

05第三方服務

本系統使用 Google OAuth、Supabase 與 GitHub Pages。這些服務可能依各自的隱私權政策處理必要的登入、資料庫或網站傳輸資訊。
